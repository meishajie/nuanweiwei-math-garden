# 暖尾尾的数字魔法花园

在线游戏：https://meishajie.github.io/nuanweiwei-math-garden/

和暖尾尾一起用数字唤醒花园。一、二、三年级各有十个地点，支持加减法、数字卡组合与生活题。年级表示练习梯度，不宣称严格覆盖某套教材或已验证教学效果。

新设备默认静音，可主动开启音乐。数学旅程无倒计时，可以暂停；奖励接星光玩法为主动开启的一分钟游戏。

无需游戏账号，进度保存在当前浏览器，不跨设备同步。清除浏览器数据可能删除进度；本地试玩记录不会自动迁入这个网址。
