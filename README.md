新一趟的选项加入同尾数、相近数量级与常见错误，小数精度统一，余数同时考查商和余数，四项完整洗牌。合理估算、口诀和验算仍被鼓励；旧暂停题继续保留原题与原选项，已有进度不清空。

封面 → 学习准备 → 数学冒险；统一选择1—4年级、三版教材、四档累计进度和轻松／标准／挑战。每年级10关，每关6题，关卡地图独立呈现。已有设置、卡片、暂停题与课程快照保留。

全题型帮助按数值选择两组圆点、减法痕迹、乘法分组、乘法试装与余数、口算拆分、逐步竖式、小数对齐和运算顺序；不会要求在九个空队里逐颗分配大数量。通关后保留霓虹舞和21张代表图的有限旅行，点图只放大当前图片；末尾可主动跳转暖尾尾微信表情。

更多设置中的“反馈与建议”接入本游戏独立的[腾讯兔小巢](https://support.qq.com/product/802218)。宽屏可在游戏内留言；手机、iPad及较窄屏幕打开完整反馈页面。打开反馈会暂停游戏声音和操作，关闭后保留原题与选项。反馈为自愿使用的第三方服务，不自动传送本地存档、答题记录或儿童身份，详情见[隐私说明](PRIVACY.md)。

和暖尾尾一起用数字点亮花园。支持1—4年级，各10站，每趟6题；新用户默认一年级、北师版、上册学完、标准难度。北师、人教、苏教三版可切换，四档累计学习进度，保留轻松／标准／挑战。已有用户保留原选择和进度，主动清空全部进度后恢复新默认值。根据所选范围练习加减、乘除、有余数除法、混合运算和相应小数计算。

同一难度内，十站也逐步增加计算和应用要求。轻松后段同样练已学的更大数；顺序为热身、主练、中途复习、迁移、收尾综合，不用未学知识加难。已学10／20范围时后段不退回5以内；仅开放5的阶段保留上限。

集齐10张卡后，带着“10关全通关啦！”的百宝箱先出现，开箱前不跳舞。亲手打开后，暖尾尾在扫动的彩色聚光灯、霓虹拱门和灯带里跳一段10秒星光舞，再自动带你参观3D表情世界。中央完整大图与两侧倾斜预览连续换位，每张约1.5秒；点图暂停细看，关闭后仍等待主动继续。一轮结束收下纪念章，可再逛、查看收藏或回花园。主动重看星光舞保留最多30秒。已有十卡直接从魔法宝藏体验，不用清档。
