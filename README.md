# 暖尾尾的数字魔法花园

[在线游戏](https://meishajie.github.io/nuanweiwei-math-garden/)

和暖尾尾一起用数字点亮花园。支持1—4年级，各10站，每趟6题；北师、人教、苏教三版可切换，四档累计学习进度，轻松／标准／挑战默认标准。根据所选范围练习加减、乘除、有余数除法、混合运算和相应小数计算。

同一难度内，十站也逐步增加计算和应用要求。轻松后段同样练已学的更大数；顺序为热身、主练、中途复习、迁移、收尾综合，不用未学知识加难。已学10／20范围时后段不退回5以内；仅开放5的阶段保留上限。

集齐10张卡后，先用“10关全通关啦！”和独立通关乐祝贺，再等孩子亲手开箱。暖尾尾用原画纹理和独立关节连续挥手、踏步、拍手、跳跃与鞠躬，配上专属欢乐舞曲，最多30秒；可暂停、收好或主动重看。纪念章之后再按需打开收藏与统计，减少动态也得到完整礼物。已有十卡可直接从魔法宝藏体验，不用清档。

可操作帮助由思考方向逐步展开到十格框、分组、竖式、运算顺序与小数位对齐。使用帮助也获得奖励。设置只影响下一趟，旧暂停题、卡片和记录保留。新设备默认静音，数学无倒计时，支持暂停。

课程依据为2026-10-13核对的24册官方公开目录，见[curriculum-sources.json](curriculum-sources.json)。部分下册仍是已正式公布的旧版或过渡版；目录未确认的细目暂不开放，不声称全面教材覆盖或已验证教学效果。

手机面板按浏览器实际可用高度排列，标题和底部按钮保留，中间内容可滚动。点击开始会在支持的Chrome／Safari中尝试全屏；iPhone普通网页不支持时可通过分享菜单添加到主屏幕。

小设置→更多设置提供“重新开始当前年级”和“清空本机全部进度”，确认后执行。当前年级重开保留课程偏好、其他年级和已有小游戏机会；更新不会主动清除存档。
