# 暖尾尾的数字魔法花园

[在线游戏](https://meishajie.github.io/nuanweiwei-math-garden/)

和暖尾尾一起用数字点亮花园。支持1—4年级，各10站，每趟6题；北师、人教、苏教三版可切换，四档累计学习进度，轻松／标准／挑战默认标准。根据所选范围练习加减、乘除、有余数除法、混合运算和相应小数计算。

可操作帮助由思考方向逐步展开到十格框、分组、竖式、运算顺序与小数位对齐。使用帮助也获得奖励。设置只影响下一趟，旧暂停题、卡片和记录保留。新设备默认静音，数学无倒计时，支持暂停。
